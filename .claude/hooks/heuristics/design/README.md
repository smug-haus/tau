# D-xxx Design Heuristics

D-xxx heuristic stubs are generated by the PSDH emitter from a project's PSDH catalog.

In the **dev repo**, this directory is empty (aside from `__init__.py` and this README). The publish pipeline generates example D-xxx stubs from the test fixture catalog when assembling the template repo.

In the **template repo**, this directory contains example D-xxx stubs demonstrating the `evaluate(window)` interface. Users regenerate project-specific heuristics by running the emitter against their own catalog:

```bash
python tools/psdh-emitter/emit.py \
  --input your-catalog.psdh.yaml \
  --targets harness-heuristic \
  --output-dir .claude/hooks/heuristics/design/
```

D-xxx heuristics use the same interface as H-xxx behavioral heuristics and are auto-discovered by the heuristic monitor.

See `docs/psdh/INTEGRATION.md` for details.
